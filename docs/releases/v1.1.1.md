提供 macOS 和 Windows 的独立下载包，解压后按 README 使用即可。macOS 包同时支持 Apple Silicon 和 Intel，Windows 包支持 PowerShell 5.1 和 PowerShell 7。

### 修复

- 配置文件最后一行重复设置已有变量时，macOS 启动器可能直接退出。
- 支持带认证信息的 HTTP/HTTPS 代理地址、IPv6 地址和省略端口的标准 URL，并检查端口范围。
- 代理连接检测增加超时，避免启动器长时间没有响应。
- 按应用可执行文件的实际路径判断是否正在运行，避免把同名 CLI 或其他安装误判成桌面应用。
- 显式指定的应用路径无效时会报错，避免悄悄打开另一个安装。
- Windows 的代理变量只传给子进程；快捷方式生成器也会读取配置文件中的应用路径。
- macOS 图标安装读取相同的配置，支持更新已安装的图标，复制后重新签名。

正常启动仍不会修改系统代理、Codex 配置或 macOS 应用包。图标安装是可选步骤。

### 下载

- **macos.zip**：macOS `.app`、启动/图标/签名脚本和配置示例。
- **windows.zip**：Windows 启动脚本、快捷方式生成器和配置示例。
- **SHA256SUMS**：两个下载包的 SHA-256 校验值。

Ready-to-use packages for macOS (Apple Silicon and Intel) and Windows (PowerShell 5.1 and 7).

Fixes cover config precedence and quoted values, authenticated and IPv6 proxy URLs, port validation, bounded connection checks, executable-path process detection, explicit application overrides, child-only proxy variables on Windows, and config-aware shortcuts and icon installation.

Normal startup still leaves system proxy settings, Codex configuration and the macOS app bundle unchanged. Icon installation remains optional.
