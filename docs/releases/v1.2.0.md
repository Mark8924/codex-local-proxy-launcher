### 独立设置窗口

- macOS 提供原生 `Codex Launcher Settings.app`，Windows 提供 `Open Launcher Settings.cmd`。
- 在界面填写代理地址、端口和应用路径，保存即可，不再要求手动编辑配置文件；旧配置继续兼容。
- 正常启动保持原样，不弹设置窗口，也不常驻后台。

### macOS 图标切换

- 在设置窗口预览并选择 ChatGPT、Codex、Space；也保留 `Change Codex Icon.command` 脚本。
- 图标仅从用户本机已安装的应用获取，不随下载包分发，也不会修改 ChatGPT 自己的图标。
- Codex、Space 支持明暗版本；默认按切换时的系统外观选择，也可用 `--appearance` 指定。
- 支持 `--app` 指定已安装的启动器，保留应用目录和 Dock 固定入口，无需重启 ChatGPT 或 Dock。
- 图标在临时副本上生成并签名，通过校验后才替换；失败时回滚。

### 签名兼容修复

处理 Finder 自动写入的 `com.apple.FinderInfo` / `com.apple.ResourceFork`，修复它们导致的签名校验失败。不清除 quarantine，也不修改系统安全设置。

Windows 的代理启动方式没有变化，仍提供独立下载包。

---

### Separate settings window

Native AppKit settings on macOS and WinForms settings on Windows. Configure the proxy in the UI without editing files; legacy config remains supported. The settings window never appears during normal launching and does not stay running in the background.

### macOS icon selection

Choose ChatGPT, Codex or Space using `Change Codex Icon.command`, or pass `--style` and `--app` to the installer. Assets come only from the locally installed app. Codex and Space support light/dark variants selected at change time.

Changes are staged, signed and verified before installation, with rollback on failure. The app directory and Dock pin stay in place; neither ChatGPT nor Dock is restarted.

Also fixes signing failures caused by Finder metadata. Quarantine and system security settings are not changed. Windows launch behavior is unchanged.
